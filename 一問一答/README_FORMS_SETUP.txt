═══════════════════════════════════════════════════
  Google Forms 出力 セットアップ手順
═══════════════════════════════════════════════════

【概要】
画像から一問一答カードを生成すると、Word と同時に
Google Forms（クイズモード・自動採点付き）も作成されます。
生成されたURLをGoogleクラスルーム等で生徒に配信できます。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
手順1: Google Cloud Console でプロジェクト作成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. https://console.cloud.google.com/ にアクセス
2. 上部の「プロジェクトを選択」→「新しいプロジェクト」
3. プロジェクト名: 任意（例: test-maker）→「作成」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
手順2: Google Forms API を有効化
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 左メニュー「APIとサービス」→「ライブラリ」
2. 検索欄に「Google Forms API」と入力
3. 「Google Forms API」をクリック→「有効にする」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
手順3: OAuth 同意画面の設定
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 左メニュー「APIとサービス」→「OAuth同意画面」
2. ユーザーの種類:「外部」を選択 →「作成」
3. アプリ名: 任意、メールアドレスを入力→「保存して次へ」
4. スコープ: そのまま「保存して次へ」
5. テストユーザー:「+ ADD USERS」で kengo1983@gmail.com を追加
6. 「保存して次へ」→「ダッシュボードに戻る」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
手順4: OAuth クライアント ID の作成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 左メニュー「APIとサービス」→「認証情報」
2. 「+ 認証情報を作成」→「OAuthクライアントID」
3. アプリケーションの種類:「デスクトップアプリ」
4. 名前: 任意 →「作成」
5. 「JSONをダウンロード」をクリック
6. ダウンロードしたファイルを以下にコピー＆リネーム:
   テスト問題作成/credentials.json

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
手順5: ライブラリのインストール
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ターミナルで実行:
  cd テスト問題作成
  pip install -r requirements.txt

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
手順6: 初回認証（初回のみブラウザが開きます）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. python generate.py を実行
2. ブラウザが自動で開き、Googleアカウントのログイン画面が表示
3. kengo1983@gmail.com でログイン
4. 「このアプリはGoogleで確認されていません」→「詳細」→「安全でないページに移動」
5. 「許可」をクリック
6. 「認証フローが完了しました」と表示されたらOK
7. 以降は token.json に保存されるので再ログイン不要

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
出力の確認
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
処理後に output/ フォルダに以下が生成されます:
  ・{画像名}.docx         ← 印刷用Wordファイル
  ・{画像名}_form_url.txt ← Google Forms のURL

Forms URLをコピーしてGoogleクラスルームに貼るだけで配信完了！

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
注意事項
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
・生成されたフォームのオーナーは kengo1983@gmail.com です
・自動採点はON（各問1点）、記述式のため表記ゆれは不正解扱い
  → フォームを開いて「回答」タブで手動採点も可能
・生徒がGoogleアカウントなしで回答させたい場合:
  フォームの「設定」→「回答」→「メールアドレスを収集する」をOFF
  「Googleにサインインが必要」をOFFにしてください
