# 書籍索引 型 v0.1

## 0. この索引は何のためにあるか

OCR全文（数十万字）を毎回読まなくても、**「この本のどの論点が、どんな問いと授業になるか」を数分で引ける**ようにするための地図。
本文の代替ではない。**要約＋所在（見出し・scan_page）＋照合キー**だけを持ち、授業で使う前に必ずOCR原文に戻る。

三層のうち、この型が受け持つのは第1層だけ。

| 層 | ファイル | ID | 今回 |
|---|---|---|---|
| 1 書籍索引（論点整理） | `BOOK-xxxx_索引.md` | `BOOK-0001` / `BOOK-0001/P-001` | **この型** |
| 2 問いカード | 別ファイル | `Q-` | 後日 |
| 3 授業設計 | 別ファイル | `L-` `T-` | 後日 |

問いカード・授業設計とは **ID だけで結ぶ**（本文をコピーしない）。

## 1. 置き場所と命名

- ファイル名: `BOOK-0001_索引.md`（番号は書籍ごとに固定。OCRのファイル名番号とは無関係）
- 置き場所: **`books/` の外**（例 `C:\projects\claude-kaihatsu\library\`）。
  理由: `import_books.py` / `import_citations.py` は Vault の `books/` を同名で上書きするため、中に置くと消える。
- 対応表 `library/book_registry.md` に `BOOK-ID ↔ OCRファイル名 ↔ ref（frontmatter）` を1行ずつ持つ。

## 2. 索引ファイルの構成

```
frontmatter
A 基本情報（書誌／OCRとの対応／収録状況／全体像／大きな問い）
B 章別情報（章ごとの位置・論点ID・章の問い）
C 論点カード（P-001〜）  ← 中心。1章あたり 3〜8 個
D 付録（OCR上の注意・数値の要確認・未収録部分）
```

### frontmatter

```yaml
---
book_id: BOOK-0001
title: 書名
authors: [著者]
year: 刊行年
ocr_file: OCRファイル名
ocr_ref: OCR側frontmatterのref
ocr_family: 1|2|3     # 1=ページ注記+重要マーク付き全文 / 2=全文のみ / 3=引用集
coverage: 全文|一部（範囲を A に明記）
index_version: 0.1
index_status: 試行|照合済|要確認
verified_by: verify_index.py（日付）
---
```

### A 基本情報

1. 書誌（書名・著者・刊行・出版社）。OCRにない情報には「OCR外・要確認」と書く。
2. OCRとの対応（ファイル名、`scan_page` と `book_page` の対応の癖）。
3. **収録状況**: どこからどこまでOCRにあるか／欠けているページ。
4. **本の全体像**（3〜5行。因果の骨格・本の主張の構造）。授業設計方針により必ず冒頭に置く。
5. **大きな問い**（この本を授業で使うときの軸になる問い。1〜2個）。

### B 章別情報

章ごとに: 見出し／scan_page範囲／章の一言要旨／含まれる論点ID／章としての問い（任意）。

### C 論点カード（書式は §4）

### D 付録

OCRの不具合（順序の入れ替わり、重要マークの位置ずれ、数字・漢字の読み取り誤り）、数値の要確認リスト、未収録部分。**本文の論点カードには不具合の詳細を書かず、ここへ集約する。**

## 3. 論点とは何か（粒度）

- **論点 = 1つの主張＋その根拠や事例のまとまり**。段落単位でも章単位でもない。目安は **0.5〜3 ページ分**。
- 1章あたり **3〜8 個**。多すぎる場合は「役割」が重なっていないか見直す。
- 見出しが付いた節は原則1論点以上。見出しがなくても、本の主張を支える転換点なら独立させる。
- 迷ったら **「これを単独で授業の1場面に使えるか？」** で切る。

## 4. 論点カードの書式

```markdown
### P-001 論点名（8〜20字。主張が分かる名詞句）
- 位置: 章「見出し」／scan_page N–M（book_page は分かるときだけ）
- 役割: 思考の道具｜反転素材｜事例・証言｜論争軸｜背景知識（主は1つ、副は括弧で）
- 状態: 照合済｜要確認
- 照合キー: `本文の短い一節`@N; `別の一節`@M
- OCR数値: `OCR上の表記`@N → 推定値（原本確認）   ※数値・年・固有名詞があるときだけ
- 【本の内容】
  著者の主張・根拠を、自分の言葉で言い換えて2〜4文。（評価・授業での使い方は書かない）
- 【教材研究の整理】
  - 素朴な認識とのずれ: 生徒（世間）が思いがちなこと → 本が示すこと
  - 問いの種: 一問一答にならない問い（なぜ／どちらが／何を根拠に）を1〜2個
  - 関連: 他の論点ID、他書のID、本書外の補足（出典つき）
```

### 役割の定義

| 役割 | 意味 | 授業での典型的な使い方 |
|---|---|---|
| 思考の道具 | 歴史を考えるための枠組み・概念 | 気づき→概念の橋渡しの「概念」側 |
| 反転素材 | 通説・思い込みをひっくり返す論点 | 導入で素朴な認識を引き出し、後で揺さぶる |
| 事例・証言 | 具体的な出来事・史料・数値 | 活動での根拠資料 |
| 論争軸 | 研究者・社会で見解が割れている点 | 立場に分かれて議論／判断を保留する練習 |
| 背景知識 | 理解の前提として必要な事実 | 説明パート（説明で完結させない） |

### 素朴な認識とのずれ

教材化の核。「生徒が最初に持っていそうな理解」と「本が示す理解」の**差**を1行で書く。差が書けない論点は、授業で使いにくい（背景知識に寄せる）。

## 5. 記入ルール

1. **本文を写さない。** 【本の内容】は言い換え。引用は照合キー（20字前後）だけ。
2. **【本の内容】と【教材研究の整理】を混ぜない。** 前者は著者の主張、後者はAI・教員の判断。
3. **所在は `見出し＋scan_page`**。`book_page` は OCR のマーカーに数字があるときだけ。推測しない。
4. **照合キー**はOCRに実在する連続した文字列（空白・改行を除いて一致）を、**論点ごとに1〜3個**。`@N` は所在の scan_page。
5. 数字・年・固有名詞は **OCR表記のまま `OCR数値:` に記録**し、推定値を矢印の先に書く。**黙って直さない。**
6. 状態は2段階のみ。`照合済`＝全照合キーがスクリプトで該当 scan_page に一致／`要確認`＝それ以外。
7. 他の本にも出てくる論点は `関連:` に `BOOK-xxxx/P-xxx` で張る（本文は書かない）。
8. 本書外の情報（外部の研究・史料）を足すときは **出典（URL・取得日）を付けて「本書外:」欄に明示**。【本の内容】には混ぜない（§7-4 参照）。
9. 引用集型（family 3）は収録状況を「一部」とし、**直接引用する前に全文OCRで照合**する。
10. 1ファイル 600 行を超えたら、章単位に分割する（`BOOK-0001_索引_ch1-3.md` など）。

## 6. 品質チェック（機械）

`verify_index.py 索引.md OCR.md` が次を検査する。

- 論点IDの重複・欠番
- 必須項目（位置・役割・状態・照合キー）の有無、役割・状態の語彙
- 照合キー／OCR数値が OCR の **指定 scan_page** に存在するか（空白・改行・HTMLコメントを除いて比較）
  - 該当ページに無く前後1ページにある → `ズレ`（マーカーが文中に入るため起こる）
  - 全文にも無い → `NG`
- `状態: 照合済` なのに NG/ズレ がある論点

## 7. 量産するとき（Claude Code）

1. 読み取り専用で OCR を読み、`ocr_family` を判定する（マーカー有無・IMPORTANT有無・引用集か）。
2. family 1 は `IMPORTANT_START` の `heading` を**論点候補の見出し**として使う（ただし failed の印は位置不明）。
3. 索引を書き、`verify_index.py` を通す。NG をゼロにするまで直す。
4. **外部情報・API の扱いは次の3層**（2026-11-01 改定。旧「API は使わない」を置換）。
   - **自由**: OCRの読み取り、スクリプト実行、Web検索・閲覧（出典URL・取得日を記録）。
   - **要確認（毎回ケンゴに事前確認）**: OCR全文や長い抜粋の外部サービスへの送信、有料APIの新規利用、個人情報の送信。
   - **禁止**: OCR・元ファイルの書き換え。外部情報による【本の内容】の補完（索引の【本の内容】は本の記述だけを根拠にする）。
   - 外部情報は `本書外:` 欄に「出典URL／取得日」つきで書き、本の内容と混ぜない。
   - 照合キーの実在確認（`verify_index.py`）と、主張の妥当性の検証は別物。照合済でも主張が正しいとは限らない。
   - 著者の留保（「〜と考えられる」等）は落とさず残す。授業で直接引用する前は原典または全文OCRで確認する。
5. 1冊ずつ人間（ケンゴ）が A（全体像・大きな問い）と役割を確認してから次へ。
