### P-011 イギリスの「一二月メモランダム」と英米の対中政策の転換

- 役割: 事例・証言（副: 反転素材）
- 状態: 照合済
- 照合キー: `イギリスはワシントン会議で決定された中国関税条約の取決めからの離脱もやむなしとし`@21; `実態のない北京政府から国民政府へと軸足を移す声明を行ったのである`@21; `寺内正毅内閣のもとで、北京の段祺瑞政権への政治借款(西原借款)を無担保で行った日本には到底できない芸当であった`@21; `二七年一月二七日、ケロッグ国務長官は、中国に対して、関税自主権のみならず治外法権撤廃をも示唆した`@21; `英米はワシントン会議で確立された対中国経済プログラムを、自ら棄てさったのである`@22
- OCR数値: `同年一二月二四日`@21 → 1926年12月24日（イギリスの「一二月メモランダム」が日本側に伝えられた日）; `二七年一月二七日`@21 → 1927年1月27日; `二・五%`・`五〇%`@21 → ワシントン付加税の率（普通品2.5%、奢侈品50%）
- 【本の内容】
  1926年12月、イギリスは「一二月メモランダム」で、ワシントン会議後に中国情勢が変わり既存条約は時代遅れになったとして、ワシントン付加税の無条件徴収を認め、関税自主権の承認も用意し、強力な中央政府ができるまで地方当局とも交渉するとした。実態のない北京政府から国民政府へ軸足を移す声明だった。担保のない西原借款を行った日本には到底できない芸当で、アメリカも27年1月、治外法権撤廃まで示唆した。著者は、国民政府の左傾化を抑え蒋介石を支持する意図があったと説明し、英米はワシントン会議で確立した対中国経済プログラムを自ら棄てたとする。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「ワシントン体制は列国の一致した枠組みだった」→ 英米のほうから、先に経済的なルールを変えた
  - 問いの種: 英米が中国の国民政府に譲歩したことは、日本の外交（内政不干渉）にどう響いたか。「債権の回収」を重視する国と、そうでない国の違いは何か。
  - 関連: P-012、P-013。

### P-012 北伐と国民政府内の対立、宇垣一成の対中政策
- 位置: 第3章「突破された3つの前提」／scan_page 22–24
- 役割: 事例・証言（副: 思考の道具）
- 状態: 照合済
- 照合キー: `北伐とは、兵力を用いて南北中国の統一をめざすものであったが、同時に、北方軍閥の「強大な武力」を覆すことによって民衆運動を発展させ、そこに国民党組織を扶植するものでもあった`@22; `これまで幣原外交を支えてきた宇垣が、英米協調のいっそうの重視という方向性ではあれ、内政不干渉方針から離れようと決意していたことが重要である`@24; `陸軍中央の主流を占める宇垣系が、幣原外交の支持基盤でなくなった意味は大きい`@24
- OCR数値: `二六年七月`@22 → 1926年7月（北伐の開始）; `同年四月七日`@23 → 1927年4月7日（宇垣陸相が若槻首相に述べた日。OCRは「同年四月七日」）
- 【本の内容】
  1926年7月、蒋介石の国民革命軍は北伐を始めた。北伐は兵力で南北中国の統一を目指すだけでなく、北方軍閥の武力を覆して民衆運動を発展させ、国民党組織を扶植するものでもあった。当時の中国共産党はソ連やコミンテルンの指導を受け、ゼネストや暴動で都市制圧を目指しており、イギリスは上海で同じ事態が起きるのを阻止せねばならなかった。27年、宇垣一成陸相は、中国の共産化は否定できず、望ましいのは「列強の協調によりて共産派を包囲する」ことだと若槻首相に述べた。著者は、これまで幣原外交を支えてきた宇垣が、内政不干渉方針から離れようと決意していたことが重要で、陸軍主流の宇垣系が幣原外交の支持基盤でなくなった意味は大きいとする。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「幣原外交は陸軍を含めて一貫して支持されていた」→ 反共のためには干渉もやむを得ないという考えが、陸軍中央にも広がった
  - 問いの種: 「内政不干渉」と「反共」は、どんな場面で両立しなくなるのか。誰が外交の支持基盤を握っているかは、外交の継続にどう影響するか。
  - 関連: P-011、P-013、P-014。

### P-013 中国側からみた新四国借款団と、ワシントン体制の掘り崩し（マクマリーの指摘）

- 役割: 論争軸（副: 思考の道具）
- 状態: 照合済
- 照合キー: `このストライキの原因の一つに新借款団に対する強い反対があった`@24; `マクマリーの指摘で優れていたのは、ワシントンとロンドン、二つの海軍軍縮条約の制限下に日本の海軍力を置くことにこそ、ワシントン体制の核心があったと見抜いていた点である`@25; `二つの体制の間で動揺する国民政府をワシントン体制の側に引き留めておくために、英米はワシントン体制の経済的ルールを変容させた。それは中国への内政不干渉政策をとる幣原外交の基盤を掘り崩すことになった`@25; `行き過ぎた行動によって、周辺諸国を安心させるのではなく、周辺国の利益と安全を保障していた国際システムを掘り崩していった`@25
- OCR数値: `二〇年春`@24 → 1920年春（五四運動以来の大規模ストライキ）; `四月一四日`@24 → 1920年4月14日（学生の全国無期限ストライキの開始）
- 【本の内容】
  著者は、新四国借款団について、中国側から見ると全く異なるイメージが現れると述べる。1920年春の学生ストライキは新借款団への強い反対も原因で、「軍閥官僚に資金援助することは国民を殺戮する武器を与えるに等しい」と訴えた。続いて、アメリカの外交官マクマリーの分析を紹介し、中国が「行き過ぎた行動によって、周辺諸国を安心させるのではなく、周辺国の利益と安全を保障していた国際システムを掘り崩した」ことが、結局は中国自身の安全と利益を掘り崩したとし、その指摘が優れていたのは、ワシントンとロンドンの二つの海軍軍縮条約の下に日本の海軍力を置くことがワシントン体制の核心だと見抜いた点だと評価する。英米が経済的ルールを変容させたことが、幣原外交の基盤を掘り崩した。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「中国のナショナリズムは国際秩序と無関係」→ 本書はマクマリーの見方を借りて、中国の行動が国際秩序の維持を損なったという見方を示す
  - 問いの種: 同じ中国の動き（ストライキ・ボイコット）は、日本側と中国側でどう違って見えるか。マクマリー覚書の見方は、何を重視し、何を見落とす可能性があるか。
  - 関連: P-011、P-017。**マクマリーの分析への評価（「優れていた」）は著者の評価で、中国側の見方とは異なる。他の見解は本書外・未調査。**

- 【本の内容】

  - 問いの種: 首相が部下の意見を退けて一人の現地指導者に固執するとき、周囲は何を考えるか。外交官が最優先にした「条約違反」問題とは何か。

  1933年11月の米ソ国交回復は、中国で蔣・汪路線に反対する孫科・宋子文・胡適らに期待を抱かせ、孫科は日本を牽制するため米ソとの連携に期待し、日本の無道は「ソ連の五カ年計画がまだ完成していないこと」と米国海軍の補強が終わっていないことによるので、3〜5年後には日本は対ソ対米戦に討って出るだろう、その時に中国にチャンスが来ると述べた。宋子文は綿麦借款を手みやげに帰国し、同じ立場だった。著者は、これを「連外抗日」路線と呼び、これに対して汪兆銘は、米ソと日本の関係が良ければ日中間に何も起きないが、有事には日本が必ず先に中国を征服し、英米ソは勝利しても、勝利までの間に中国は必ず破壊される、国を荒野にする前に日本との交渉が必要だと考え、これを「対日交渉路線」と呼ぶ。蔣は基本的に汪と同じだが、対ソ政策では異なっていた。35年までの国民政府の外交は、汪に代表される対日交渉路線が主流で、水面下に孫科に代表される連外抗日路線があった。
