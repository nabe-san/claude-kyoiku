- 【本の内容】
  米は朝鮮戦争の休戦直後にSEATOを設立した（NATOのアジア版で、中ソから南ベトナムを守る備え）。朝鮮と同様にインドシナの休戦も現地の分断を条件にして、アジアの緊張緩和を図った。ベトナムの分断で対立は構造化されたが、米英仏中ソが現地の不満を抑えてまで「平和共存」による解決を求めたのは、どの国も軍事費の負担から逃れたかったからだ、と著者は述べる。
- 【教材研究の整理】

  - 問いの種: 大国が合意して平和を作るとき、その犠牲は誰が負うのか。軍事費の負担は、国の外交方針をどこまで左右するのか。
  - 関連: P-042、P-046。

- 【本の内容】

- 【教材研究の整理】
  - 素朴な認識とのずれ: 「平和共存は核の恐怖から生まれた」→ 本書は、第三世界の台頭も大国を合意へ向かわせたと見る
  - 問いの種: 「核兵器が戦争を抑止する」という考えは、誰にとって、どんな条件で成り立つか。第五福竜丸の被爆は、その考えとどうぶつかるか。

### P-049 日ソ共同宣言と国連加盟、北方領土問題
- 位置: 第4章「『第三世界』と『平和共存』」／scan_page 32–33
- 役割: 論争軸（副: 事例・証言）
- 状態: 照合済
- 照合キー: `ソが日本の国連加盟を支持するとともに、戦犯容疑者を釈放・帰還させ、日本に対する一切の賠償請求権を放棄する`@32; `北方領土の全面返還であるのか、歯舞色丹の二島返還であるのか、その点を不明確にしたまま交渉を進めていた`@33; `国後・択捉の返還を領土問題として提起する機会は失われた`@33; `ソは歯舞・色丹の返還をも撤回することになる`@33
- OCR数値: `五六年一二月`@33 → 1956年12月（日本の国連加盟）
- 【本の内容】
  フルシチョフの平和共存路線の中で日ソ交渉が再開され、鳩山首相が訪ソして日ソ共同宣言が結ばれた。ソ連は日本の国連加盟を支持し、戦犯容疑者の釈放・帰還と賠償請求権の放棄を約し、日本は国連に加盟して経済交流も復活した。領土問題は、北方領土の全面返還か二島返還かが不明確なまま交渉され、ソ連は平和条約後に歯舞・色丹を返還するとしたが、以後は二島返還で合意したとされ、国後・択捉の返還を提起する機会が失われたと著者は述べる。60年の安保改定で、ソ連は歯舞・色丹の返還も撤回した。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「北方領土問題は戦後すぐからの課題で一貫している」→ 国連加盟を優先して、領土問題を曖昧にしたまま国交を回復した経緯がある
  - 問いの種: 領土問題を棚上げしても国交を優先した判断は、何を得て何を失ったか。条約の文言が曖昧であることは、後の交渉をどう制約するか。
  - 関連: P-035、P-060。領土問題の扱いについての他の見方は本書外・未調査。

### P-050 スプートニク・ショックと軍縮の機会喪失

- 役割: 反転素材（副: 思考の道具）
- 状態: 照合済
- 照合キー: `ソは翌八月に大陸間弾道ミサイル(ICBM)の開発に成功し`@34; `フルシチョフがその優位を世界に公言しながらも、同時に米に対して訴えたのは意外にも軍縮であった`@34; `ところが、米がこの提案に乗ることはなかった`@34; `ソに科学技術で抜かれた米の狼狽が軍縮の機会を逸したのである`@34
- OCR数値: `一九五七年七月`@34 → 1957年7月（IAEA設立）; `九六分`@34 → 96分（スプートニクの周回時間）
- 【本の内容】
  西側は1957年7月にIAEAを設立して核の統制を考えたが、ソ連はその翌月にICBMの開発に成功し、10月には人工衛星スプートニクの打ち上げにも成功して、核兵器が宇宙から落とせるかのような印象を与えた。しかしフルシチョフが米に訴えたのは軍縮で、核兵器の生産・使用の永久禁止を提案し、ソ連軍の大幅縮小と核実験の停止まで実施した。米は提案に乗らずミサイル開発を進め、米の衛星打ち上げは失敗した。著者は、科学技術で抜かれた米の狼狽が軍縮の機会を逸したと見る。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「技術で優位に立った側が軍拡を進める」→ 優位に立ったソ連が軍縮を提案し、米が拒んだ
  - 問いの種: 優位に立った側が軍縮を求める理由は何か。米が提案に乗らなかったのは、何を恐れたからか。
  - 関連: P-046、P-051。ソ連の軍縮提案の動機の解釈は著者のもの（本書外・未調査）。

### P-051 キューバ革命とベルリンの壁
- 位置: 第4章「『第三世界』と『平和共存』」／scan_page 35–36
- 役割: 事例・証言
- 状態: 照合済
- 照合キー: `わずか十数人の若者から開始され、二年余で成功したキューバ革命は、世界中の若者に反響した`@35; `作戦失敗によって米はキューバへの影響力を失い、また世界的にも非難を浴びた`@36; `ソは強硬手段に訴えて「ベルリンの壁」を建設した`@36; `軍縮の機会を自ら逃した米が南米での外交に躓くと、欧州の分断が促進されたのである`@36
- OCR数値: `六一年一月`@36 → 1961年1月（米・キューバ国交断絶）; `六〇年五月`@35 → 1960年5月（U2撃墜。本書はU2に「(BlackBird)」の注を付けるが、機体名の記述は要確認）; `六一年四月`@36 → 1961年4月（有人宇宙飛行）
- 【本の内容】
  キューバでは米の支援を受けたバティスタの独裁に対して、カストロやゲバラらが蜂起し、2年余で政権を倒した。米はキューバに経済制裁を行い、カストロが砂糖の買い入れをソ連に頼ると国交を断絶し、ケネディ政権は亡命者によるピッグス湾侵攻を援護したが失敗した。一方、ソ連は有人宇宙飛行にも成功し、ベルリンから撤退を求めて「ベルリンの壁」を建設した。著者は、軍縮の機会を逃した米が南米外交でつまずいたことが、欧州の分断を促進したと述べる。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「キューバ危機は突然始まった」→ 革命から経済制裁、国交断絶、侵攻失敗という前段がある
  - 問いの種: 経済制裁は、相手国をどの陣営に近づける働きをするか。ベルリンの壁を西側が「黙認」したのはなぜか。
  - 関連: P-050。フルシチョフのディズニーランドの逸話（scan 35）は本索引では扱わない。

### P-052 保守合同と二つの「自主外交」
