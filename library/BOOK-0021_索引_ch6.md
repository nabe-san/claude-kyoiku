### P-065 アフリカの年とコンゴ動乱
- 位置: 第6章「世界観が生み出す対立」／scan_page 53–54
- 役割: 事例・証言（副: 背景知識）
- 状態: 照合済
- 照合キー: `一九六〇年には一七ヵ国もの独立があり、「アフリカの年」と呼ばれた`@53; `総会の四分の一をアフリカ諸国が占めるようになり、国連決議を左右する存在となった`@53; `首相を暗殺して親米政権を創出しようとしたが、混乱が増しただけの結果になり`@53
- OCR数値: `一七ヵ国`@53 → 17カ国（1960年の独立国数）; `六五年`@53 → 1965年（モブツのクーデター）
- 【本の内容】
  1960年には17カ国が独立して「アフリカの年」と呼ばれた。独立国が国連に加盟し、総会の4分の1をアフリカ諸国が占めて決議を左右する存在になった。ベルギーから独立したコンゴは、親米派の大統領と親ソ派の首相に政府が分裂し、61年に米のCIAが首相を暗殺して親米政権を創ろうとしたが混乱を増すだけに終わり、65年にモブツが米の支援で軍事政権を打ち立てて動乱は収束した。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「アフリカは冷戦と無関係」→ 独立国が国連の票を持つことで、冷戦の舞台になった
  - 問いの種: 独立国の数が増えることは、国連の意思決定をどう変えるのか。大国が他国の指導者を排除しようとするとき、何が失われるか。
  - 関連: P-044（第三世界）、P-091（国連の票の変化）。CIAの関与の記述は本書の本文のみ（出典は本書外・未調査）。

- 役割: 反転素材（副: 背景知識）
- 状態: 照合済

- OCR数値: `五六年の「経済白書」`@55 → 1956年の経済白書; `六〇年一一月の総選挙`@55 → 1960年11月
- 【本の内容】
  池田は岸内閣の強権性を修正するために「低姿勢」「寛容と忍耐」を掲げ、60年の総選挙に大勝し、公約の国民所得倍増計画が民間の設備投資を誘発して高度成長につながったとされる。56年の経済白書の「もはや戦後ではない」は、日本が既に発展したという意味だと誤解されがちだが、白書の本文は、回復による浮揚力はほぼ使い尽くされ、回復を通じた成長は終わり、今後は近代化で支える必要があるという警告だった、と著者は述べる。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「もはや戦後ではない＝復興を達成した宣言」→ 本書は、白書の本文を引いて「今後は簡単には伸びない」という警告だったと説明する
  - 問いの種: 有名な標語は、なぜ元の文脈から離れて広まるのか。白書の文章を読むと、標語の意味はどう変わるか。

- 役割: 背景知識
- 状態: 照合済
- 照合キー: `「神武景気」が起きた`@56; `それまで主要な産業部門であった石炭・海運産業に代わって、鉄鋼・化学・石油精製が大きく成長した`@56; `国民の一部には「中流意識」が広がった`@56
- OCR数値: `三一ヵ月間`@56 → 31カ月間（神武景気）; `約四二ヵ月間`@56 → 約42カ月間（岩戸景気）
- 【本の内容】
  55年の大豊作で食糧難を脱し、朝鮮特需を元にした好況が31カ月続く「神武景気」が起き、家電の「三種の神器」が普及し始めた。58年からは約42カ月の「岩戸景気」となり、神武景気の利潤を元手にした民間の設備投資が連鎖して長期の好況を促した。石炭・海運に代わって鉄鋼・化学・石油精製が成長し、電機・精密機械・自動車も伸び、サラリーマンや労働者の収入の急増から国民の一部に「中流意識」が広がり、さらに「いざなぎ景気」へ向かう。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「高度成長は一つの長い好景気」→ 神武・岩戸・いざなぎと、段階ごとに産業構造が入れ替わった
  - 問いの種: 石炭から石油への転換は、産業と暮らしを何から何へ変えたのか。「中流意識」は、事実としての平等と同じものなのか。

- OCR数値: `一三日間`@58 → 13日間（キューバ危機の期間）; `六二年一〇月`@57 → 1962年10月
- 【本の内容】

### P-071 宏池会と「所得倍増」の実際（派閥政治の原点）
- 位置: 第6章「世界観が生み出す対立」／scan_page 61–63
- 役割: 背景知識（副: 事例・証言）
- 状態: 照合済
- 照合キー: `宏池会は、大蔵官僚を中心に経済政策を検討する集団として成立し`@61; `自民党の派閥政治の原点にもなった`@61; `「一〇年後の国民生活をヨーロッパ並みに」すると宣伝し`@61; `IMF(国際通貨基金)8条国に移行し`@62; `「安い石油」と「安い円」は原材料の輸入に好影響を与え`@63
- OCR数値: `一九六五年までに日本の対米貿易が黒字に転じる`@63 → 1965年（対米貿易黒字化）
- 【本の内容】
  池田は岸内閣の改造で閣外に出され、その時に派閥「宏池会」が立ち上がった。大蔵官僚を中心に経済政策を検討する集団で、大平正芳・宮沢喜一らが加わり、機関紙を発行して公然と旗揚げし、自民党の派閥政治の原点になった。内部の経済研究会から「所得倍増」が出た。池田は緊縮財政の官僚政治家と見られがちだが、「10年後の国民生活をヨーロッパ並みに」と宣伝し、道路・港湾など五輪関連の事業を進めた。主要エネルギーが石炭から安い石油に移り、円の固定相場で輸出が有利になり、日本はIMF8条国に移行し、65年までに対米貿易が黒字に転じた。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「所得倍増は政治家のスローガン」→ 経済研究の集団から政策として組み立てられた
  - 問いの種: 政治の集団（派閥）が政策づくりの集団として始まることには、どんな利点と問題があるか。「安い石油」と「安い円」は、高度成長にどう働いたか。
  - 関連: P-067、P-072。

### P-072 「一九四〇年体制」：高度成長の戦前との連続性
- 位置: 第6章「世界観が生み出す対立」／scan_page 63
- 役割: 思考の道具（副: 反転素材）
- 状態: 照合済
- 照合キー: `「高度成長」には戦前からの連続性があった`@63; `企業が資金を調達する際に、政府が銀行を通じて統制する「間接経済」を基礎とした`@63; `「企業別組合」は、その後日本の特徴的な組合のあり方となり`@63; `これら戦前の経済体制・「一九四〇年体制」による特徴や傾向は、日本経済の高度化を進める途上で敗戦を迎えたために、表面的には断絶されたかに見えた`@63
- OCR数値: `三〇〇万トン`@63 → 300万トン（37年時の鉄鋼生産設備）; `五六〇万トン`@63 → 560万トン（終戦時）
- 【本の内容】
  著者は、高度成長には戦前との連続性があったと述べる。企業が資金を銀行経由で調達し、政府が統制する「間接経済」は、戦時に戦争資金を確保するための構造で、大蔵省の影響力を高めた。戦時に重化学工業へ資金が配分され、鉄鋼設備は37年の300万トンから終戦時の560万トンに成長し、技術者・労働者も池田政権期に生存していた。下請制度も戦後に引き継がれ、戦時の「産業報告会」を母体にした企業別組合は日本の特徴的な組合のあり方となり、金融機関と系列企業の結合を促した。これらは敗戦で断絶したかに見えたが、実際は高度成長の土台だった。
- 【教材研究の整理】
  - 素朴な認識とのずれ: 「戦後に仕組みが一新されて奇跡の成長が起きた」→ 戦時期の制度が、形を変えて土台になった
  - 問いの種: 「戦前と戦後の断絶」と「連続」は、同じ出来事のどこを見ているのか。戦時の制度が戦後に引き継がれた例は、他にどんなものがあるか。
  - 関連: P-070、P-071。「一九四〇年体制」論の位置づけ（研究史）は本書外・未調査。
