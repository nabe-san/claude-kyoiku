# テスト問題改善

`テスト問題作成/input/improve/` に改善したい問題ファイルを置いてから実行します。
問題ごとに診断・改善案・代替案を生成して `output/reports/` にWord出力します。

## 実行手順

### Step 1: improve フォルダの確認

まず `テスト問題作成/input/improve/` の中身を確認してください。

- ファイルがない場合は「`テスト問題作成/input/improve/` に改善したい問題ファイル（.docx または .pdf）を置いてください」と伝えてください。
- ファイルがあれば Step 2 へ進む。

### Step 2: スクリプト実行

以下のコマンドを実行してください。

```bash
cd "c:\Users\kengo\Desktop\claude開発\テスト問題作成" && python improve.py
```

### Step 3: 完了報告

実行が完了したら、生成されたファイルを以下の形式で報告してください。

**生成完了：**
- `output/reports/<ファイル名>_改善レポート.docx`

エラーがあった場合はその内容を伝えて、原因を説明してください。
