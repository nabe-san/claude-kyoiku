# 引用差し替え

公開済みの読書ノート（`src/content/books/[slug].md`）にある引用の中に気に入らないものがあるとき、
Vault（`books-vault/[slug].md`）に蓄積された未公開の候補から選び直して差し替える。

**絶対原則：Vaultの中身（未公開候補の引用文そのもの）は、このチャットでの表示以外のどこにも書き出さない。**
新規ファイルを作らない、`src/content/` 以外に書き込まない、Vaultをgit管理に入れない。
著作権上の理由でVaultはGitHub・Vercelに一切送らない設計になっている（`rekishi-hp/CLAUDE.md` 参照）。

## 実行手順

### Step 1: 対象の本を特定する

`<slug>` が渡されていなければ、書名か本のslugを尋ねる。
`rekishi-hp/books-vault/[slug].md` と `rekishi-hp/src/content/books/[slug].md` の両方が存在することを確認する。
どちらか片方しかない場合はその旨を伝えて中断する（Vaultがない＝候補がない、公開ファイルがない＝まだpublishされていない）。

### Step 2: 公開済みの引用を一覧表示する

`src/content/books/[slug].md` を読み、見出し（`## `）を番号付きで一覧表示する。

```
【現在公開中の引用（<書名>）】
1. 三国干渉とロシアの満洲鉄道計画
2. 台湾総督府の設置と権限
...
```

「どれを差し替えたいですか？」と尋ねる。

### Step 3: 未公開の候補を一覧表示する

`books-vault/[slug].md` を読み、見出しを公開済みファイルと突き合わせて「Vaultにはあるが未公開」のブロックだけを抽出する。

- 各候補を番号付きで表示する：見出し・引用文（全文）・`<!-- concepts: ... -->` のタグ
- Step 2 で指定された引用と概念タグを共有する候補があれば、それを先頭に優先表示する（テーマが近く選びやすいため）。残りも省略せず全部表示する
- 表示前に、以下の基準で明らかに質が低い候補には印を付ける（除外はしない、あくまで参考情報として教師に見せる）：
  - 30字未満の極端に短い引用
  - 同一文の反復ループになっている
  - 文が途中で切れており、前後のブロックにも続きが見当たらない

「どの候補に差し替えますか？（番号でお答えください）」と尋ねる。

### Step 4: 概念タグと出典の整合性を確認する

選ばれた候補について：

- `<!-- concepts: ... -->` のタグが `src/data/concepts/*.json`（マスター語彙）に含まれているか確認する
  - 含まれていないタグ（例：「新規タグ候補: 華夷秩序」のような書きかけの表記）は、マスター語彙内の近い概念に言い換えるか、教師に確認してから決める。語彙にない語をそのまま公開タグにしない
- 出典行（`*著者名『書名』（年）*`）がVault側に無い場合は、`books-vault/[slug].md` のfrontmatter（title/author/year）から補って生成する
- 引用文そのものは一字一句変えない

### Step 5: 差し替えを実行する

`src/content/books/[slug].md` の該当ブロック（見出し・引用・出典・conceptsタグの4行セット）だけを、選ばれた新しい引用に置換する。

- 他のブロック、frontmatter（`summary` 等）には触れない（引用1個の差し替えで論旨が大きく変わる場合のみ、教師に `summary` の見直しが必要か確認する）
- `relatedUnits` は変更しない
- 1回の実行で差し替えるのは1本だけ。複数差し替えたい場合もStep 5〜7を1本ごとに繰り返す

### Step 6: ビルド確認

```bash
cd rekishi-hp && npx astro build
```

エラーが出た場合は原因を説明し、差し替え内容を修正する。

### Step 7: コミット・公開の確認

ビルドが通ったら「この内容でコミットしてpushしてよいか」を教師に確認する。承認が得られたら：

```bash
git add src/content/books/[slug].md
git commit -m "読書ノート: <書名>の引用を差し替え"
git push
```

Vercelが自動デプロイする。push後、以下の形式で報告する：

```
## 引用差し替え完了：<書名>

- 差し替え前: 「<旧見出し>」
- 差し替え後: 「<新見出し>」
- conceptsタグ: <タグ一覧>
- コミット: <コミットメッセージ>
```
