# 授業自動生成

`授業自動生成/input/<授業回名>/` に教科書画像（4枚程度）を入れてから実行します。
一問一答カード・テスト問題・歴史シミュレーションを一括生成して `output/` に出力します。

## 実行手順

### Step 1: input フォルダの確認

まず `授業自動生成/input/` の中身を確認し、授業回フォルダと画像が入っているかチェックしてください。

- フォルダがない場合は「`授業自動生成/input/` に授業回フォルダ（例: `01_産業革命/`）を作成して、教科書画像（.jpg/.png）を入れてください」と伝えてください。
- フォルダがあれば Step 2 へ進む。

### Step 2: スクリプト実行

以下のコマンドを実行してください。

```bash
cd "c:\Users\kengo\OneDrive\デスクトップ\claude開発\授業自動生成" && python generate.py
```

所要時間は授業回 1 件あたり約 2 分です。

### Step 3: 完了報告

実行が完了したら、生成されたファイルを以下の形式で報告してください。

**生成完了：**
- `output/<授業回名>/一問一答カード.docx`
- `output/<授業回名>/テスト問題.docx`
- `output/<授業回名>/歴史シミュレーション/index.html`

エラーがあった場合はその内容を伝えて、原因を説明してください。
