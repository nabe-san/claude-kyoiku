# 確認テスト生成

授業の文字起こしテキストから、4択確認テストを生成します。

## 実行手順

ユーザーがテキストを提供したら、以下のルールで4択問題を15〜20問生成してください。

### ルール
- 授業で説明された重要な概念・事実・因果関係から出題する
- 各問題に選択肢を4つ（正答1つ・誤答3つ）作る
- 誤答は紛らわしいが明確に間違いのある選択肢にする
- 15〜20問作成する
- テキストに書かれた内容のみから出題する

### 出力形式

以下の形式でMarkdownとして出力してください：

**【問題】**

**問1．** ○○の特徴として正しいものはどれか。

　① 選択肢A  
　② 選択肢B  
　③ 選択肢C  
　④ 選択肢D  

（以降同様に全問出力）

---

出力後に、答えだけをまとめた解答欄も出力してください：

**【解答】**

| 問 | 答 | 問 | 答 | 問 | 答 |
|----|----|----|----|----|----|
| 1 | ② | 2 | ④ | 3 | ① |
| … |   |   |   |   |   |

### テキストが提供されていない場合
「確認テストにしたい授業の文字起こしを貼り付けてください」と伝えてください。
