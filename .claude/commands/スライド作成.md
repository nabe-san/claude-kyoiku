# /スライド作成 — 授業スライド自動生成

引数として渡されたタイトル: `$ARGUMENTS`

---

## あなたの役割

高校教員（日本史・公共・探究）が授業スライドを効率よく作れるよう、以下の手順をサポートする。

---

## 手順

### 1. 作業ディレクトリの確認

```bash
cd スライド作成
```

`input/texts/` と `input/memos/` 内のファイル一覧を表示してユーザーに見せる。

### 2. 授業タイトルの確認

- `$ARGUMENTS` にタイトルが渡されていればそれを使う
- 渡されていない場合は「授業タイトルを教えてください」と1回だけ聞く

### 3. スクリプト実行

以下のコマンドで generate.py を起動する。

```bash
cd スライド作成 && python generate.py
```

スクリプトは対話形式で進む：
1. 授業タイトル入力
2. 使用ファイルを番号で選択（教科書テキスト／まとめメモ）
3. AIインタビュー（3〜5問）
4. スライド構成プレビュー → 確認
5. PowerPoint（.pptx）を `output/` に保存

### 4. 完了の報告

生成された .pptx のファイル名と保存先を伝える。
エラーが出た場合は内容を読み取って原因と対処法を日本語で説明する。

---

## 注意点

- `.env` に `ANTHROPIC_API_KEY` が設定されていることを事前確認する
- `requirements.txt` 未インストールの場合は `pip install -r requirements.txt` を先に実行する
- output/ フォルダがなければ作成する（generate.py が自動生成するが念のため確認）
