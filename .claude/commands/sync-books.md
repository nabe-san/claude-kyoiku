# sync-books

Google Drive の `BOOK_MERGED` フォルダとローカル `books/` を同期する。
新規ファイルのみダウンロードし、既存ファイルは重複しない。

---

## 実行手順

### Step 1: マニフェスト読み込み

`books/.manifest.json` を読み込む。存在しない場合は空の辞書 `{}` とする。

形式:
```json
{
  "driveFileId_xxxxx": "ローカルファイル名.txt"
}
```

### Step 2: Drive ファイル一覧取得

`mcp__claude_ai_Google_Drive__search_files` を実行する。

- query: `parentId = '1yidY2x_315rfYvwC3yPaMlgv7B00x87m'`
- pageSize: 50
- `next_page_token` がある場合は全件取得するまでページネーションを繰り返す

### Step 3: ローカルファイル一覧取得

`books/` フォルダのファイル一覧を取得する（`.manifest.json` は除外）。

### Step 4: 各 Drive ファイルについて判定

各 Drive ファイルに対して以下の順で判定する:

**パターンA: マニフェストに file ID が記載済み**
→ スキップ（処理済み）

**パターンB: マニフェット未記載だが、ローカルに類似ファイルが存在する**
→ マニフェストに追記してスキップ（新規ダウンロード不要）

類似判定の方法:
1. Drive ファイル名から `_MERGED` を除去したものを「核心名」とする
2. ローカルファイル名から先頭の番号プレフィックス（例: `06_`）を除去し、拡張子も除去
3. 「核心名」が上記のローカル名に部分一致（contains）すれば類似とみなす

**パターンC: マニフェット未記載かつローカルに対応ファイルが見つからない**
→ ダウンロード対象とする

### Step 5: 新規ファイルのダウンロードと保存

ダウンロード対象ファイルに対して:

1. `mcp__claude_ai_Google_Drive__read_file_content` でファイル内容を取得
2. ローカルファイル名を決定する:
   - Drive ファイル名から `_MERGED` を除去
   - ファイル名として使えない文字（`/` `\` `:` `*` `?` `"` `<` `>` `|`）をアンダースコアに置換
   - 末尾に `.txt` を付ける
   - 例: `アジアのナショナリズム_MERGED` → `アジアのナショナリズム.txt`
3. `books/<ファイル名>` として保存
4. マニフェストに `{driveFileId: ローカルファイル名}` を追記

### Step 6: マニフェスト保存

更新したマニフェストを `books/.manifest.json` に保存する。

### Step 7: 結果報告

以下の形式で報告する:

```
## sync-books 完了

- 既存ファイル（スキップ）: N 件
- 新規ダウンロード: N 件
  - ファイル名1.txt
  - ファイル名2.txt
- エラー: N 件（あれば詳細を表示）
```
