# 調べものログ（知識ログアプリ）

スマホの読書中・移動中に気になった人物・用語・出来事をその場で1タップ送信し、
週1回まとめてWeb検索＋要約し、メールでダイジェストを受け取るツール。
最終的にはメール本文をコピーしてObsidianに貼り付ける想定。

## 全体の流れ

```
[iPhone PWA] --POST--> [GAS Web App] --追記--> [中継スプレッドシート]
                                                        |
                                          （週次トリガー）|
                                                        v
                                          [GAS 週次バッチ]
                                          Claude API + web_search で要約
                                                        |
                                                        v
                                          [Gmail: 週次ダイジェストメール]
                                                        |
                                          （手動コピペ）  |
                                                        v
                                              [Obsidian Vault]
```

## フォルダ構成

```
知識ログ/
├── CLAUDE.md         ← この設定手順書
├── pwa/               ← スマホ側キャプチャ画面（PWA）
│   ├── index.html
│   ├── app.js          （送信処理・オフラインキュー）
│   ├── manifest.json
│   └── service-worker.js
└── gas/                ← Google Apps Script（1つのGASプロジェクトにまとめる）
    ├── appsscript.json
    ├── Config.gs        （非秘密設定：シートID・送信先メール・モデル名）
    ├── WebApp.gs         （doPost：スマホからの受信 → シートへ追記）
    └── WeeklyBatch.gs    （週次処理：Claude要約 → メール送信）
```

## セットアップ手順

### 1. 中継スプレッドシートを作成

1. [sheets.google.com](https://sheets.google.com) → 「空白」で新規スプレッドシートを作成
2. 名前は任意（例：「知識ログ_中継」）
3. URLが `https://docs.google.com/spreadsheets/d/【ここ】/edit` の形になっているので、`【ここ】` の部分（英数字の羅列）をコピーして控えておく（＝スプレッドシートID）

### 2. GASプロジェクトを作成

1. 手順1のスプレッドシートを開いたまま、メニュー「拡張機能」→「Apps Script」をクリック
2. 新しいタブでGASエディタが開く（このシートに紐づくプロジェクトができるが、コード側は`SpreadsheetApp.openById()`でIDを直接指定するので紐付け自体に依存しない）

### 3. 4つのファイルを貼り付け

1. 左側ファイル一覧にデフォルトで `コード.gs` がある。これを開いて中身を全消去し、`gas/Config.gs` の内容を貼り付け、ファイル名を `Config` に変更（ファイル名の右の「⋮」→「名前を変更」）
2. ファイル一覧の「ファイルを追加」（+アイコン）→「スクリプト」→ ファイル名 `WebApp` で作成 → `gas/WebApp.gs` の内容を貼り付け
3. 同様に `WeeklyBatch` というファイルを作成 → `gas/WeeklyBatch.gs` の内容を貼り付け
4. 左側の歯車アイコン「プロジェクトの設定」を開き、一番下の「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェック
5. エディタ画面に戻るとファイル一覧に `appsscript.json` が現れる → クリックして中身を全消去し、`gas/appsscript.json` の内容を貼り付け
6. Ctrl+S（または画面上部の保存アイコン）で保存

### 4. 非秘密設定を編集

`Config.gs` を開き、`CONFIG` を実際の値に書き換えて保存：

```js
const CONFIG = {
  QUEUE_SHEET_ID:   '手順1で控えたスプレッドシートID',
  QUEUE_SHEET_NAME: 'キュー',
  DIGEST_TO:        '自分のGmailアドレス',
  CLAUDE_MODEL:     'claude-opus-5',
};
```

### 5. 秘密情報をスクリプトプロパティに登録

1. 左側の歯車アイコン「プロジェクトの設定」→ 下にスクロールして「スクリプト プロパティ」欄
2. 「スクリプト プロパティを追加」をクリックし、1つ目を登録：

   | プロパティ | 値 |
   |---|---|
   | `ANTHROPIC_API_KEY` | `sk-ant-...`（[console.anthropic.com](https://console.anthropic.com) → 左メニュー「API Keys」→「Create Key」で取得。他のツール（授業記録など）で既に使っているキーがあっても、スクリプトプロパティはGASプロジェクトごとに独立しているので改めて貼り付ける必要がある） |

3. もう一度「スクリプト プロパティを追加」で2つ目を登録：

   | プロパティ | 値 |
   |---|---|
   | `SHARED_TOKEN` | 推測されにくい適当な文字列。自分で決めてもよいし、`openssl rand -hex 12` 等で生成した文字列でもよい（例: `822e2090c0fd8f47c0a3bc07`）。**この値は手順9でPWA側にも同じものを入力する** |

4. 「保存」ボタンをクリック

### 6. スプレッドシートのヘッダーを作成

1. エディタ上部、実行ボタン（▶）の左にある関数選択プルダウンから `setupSheet` を選ぶ
2. ▶実行をクリック
3. 初回は「承認が必要です」という画面が出る → アカウントを選択 →「詳細」→「（プロジェクト名）に移動」→「許可」（スプレッドシートへのアクセス許可を求められるので許可する）
4. 下部の「実行ログ」に「ヘッダー行を作成しました ✓」と出れば成功。スプレッドシートを見ると「タイムスタンプ／クエリ／状態／メモ」の見出し行ができている

### 7. 週次トリガーを設定

1. 関数選択プルダウンから `setupTrigger` を選ぶ → ▶実行
2. 実行ログに「毎週日曜20時のトリガーを設定しました ✓」と出れば成功
3. 時間や曜日を変えたい場合は `WeeklyBatch.gs` の `setupTrigger()` 内の `.onWeekDay(...)` / `.atHour(20)` を編集してから再実行する

### 8. Web Appとしてデプロイ

1. 右上の青い「デプロイ」ボタン →「新しいデプロイ」
2. 「種類の選択」の歯車アイコンをクリック →「ウェブアプリ」を選択
3. 「次のユーザーとして実行」: **自分**
4. 「アクセスできるユーザー」: **全員**
5. 「デプロイ」をクリック → ここでも権限の確認画面が出ることがあるので許可する
6. 完了画面に表示される「ウェブアプリ」のURL（`https://script.google.com/macros/s/xxxxx/exec` の形）をコピーして控える（＝PWA側の設定で使うURL）

> 認証はGoogleログインではなく、手順5で決めた共有トークンで行う（`doPost`内でトークンを照合しているため、URLを知っているだけでは書き込めない）。
>
> **後でコードを修正した場合**：GASエディタ上のコードを直しただけでは、既にデプロイ済みの`/exec`URLには反映されない。「デプロイの管理」→ 該当デプロイの鉛筆アイコン →「バージョン」を「新バージョン」に変更 →「デプロイ」で反映させる。

### 9. PWAを公開する（要相談）

`pwa/` フォルダ内の4ファイルをHTTPSで配信できる場所に置く必要がある（iPhoneで「ホーム画面に追加」するにはHTTPS配信が必須）。このリポジトリのルートは既にGitHub Pagesとして公開されている構成なので `知識ログ/pwa/` を配置してpushする方法が最短だが、**このリポジトリのローカルmainとGitHub側（origin/main）は既に分岐しているため、そのままpushするのは避ける**。公開方法（分岐を解消してpush／別リポジトリ／Netlify等）は別途相談して決める。

### 10. iPhoneで初期設定

1. 手順9で公開したURLをSafariで開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動 →「⚙ 送信先の設定」を開き、手順8のURLと手順5のトークンを入力して保存

## 動作確認

1. PWAから適当な語句を送信 → スプレッドシートに `pending` 行が追加されることを確認
2. GASエディタで `testRun` を実行 → ログで成功/失敗を確認、行が `processed` になっているか確認
3. 設定したGmailにダイジェストメールが届くか確認
4. メール本文をコピーしてObsidianに貼り付け、Markdownとして正しく表示されるか確認（要実機確認 — うまく崩れる場合はメール送信部分の改行コード処理を見直す）

## 診断

`checkConfig` 関数を実行すると、設定値・APIキー・トークンの登録状況・スプレッドシートへのアクセス可否をログに出力する。
