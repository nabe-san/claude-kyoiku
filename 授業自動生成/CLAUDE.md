# CLAUDE.md — 授業自動生成

このフォルダ専用の指示書。`generate.py` の動作・プロンプト設計はここを優先する。

---

## 目的

教科書の授業回ページ（画像 4 枚程度）から以下の 3 点を一括自動生成し、`output/` に保存する。

| 出力物 | 形式 | 概要 |
|---|---|---|
| 一問一答カード | Word (.docx) | 重要語句の空欄補充カード 20〜30 枚 |
| テスト問題 | Word (.docx) | 4 択・年代整序 20 問 + 解答・解説 |
| 文字資料 | Word (.docx) | 因果関係・背景・結果を短文の矢印チェーンで示す行間補完資料 |

> 歴史シミュレーションは Claude Code との対話形式で別途作成する（`歴史シミュレーション/` フォルダ参照）。

```
        ├── 一問一答カード.docx
        ├── テスト問題.docx
        ├── 文字資料.docx
        └── analysis.txt    ← Phase 1 分析テキスト（キャッシュ）
```

## 実行方法

```bash
cd 授業自動生成
python generate.py           # 未処理フォルダのみ生成
python generate.py --force   # 出力済みフォルダも強制再生成
```

スキルからも実行できる：Claude Code で `/授業自動生成` と入力。

## 処理フロー

```
input/<授業回>/画像
      ↓
  Phase 1（共有）
  Claude Vision で画像を一括分析
  → analysis.txt に保存（キャッシュ）
      ↓              ↓              ↓
  Phase 2a       Phase 2b       Phase 2c
  一問一答カード  テスト問題     文字資料
  (Word)         (Word)         (Word)
```

- Phase 1 はキャッシュがあれば再実行しない（API 節約）
- Phase 2a・2b・2c はどれかが失敗しても残りは続行する
- 3 ファイルが揃っている授業回は `--force` なしではスキップ

## 各出力物の方針

### 一問一答カード

- 人名・地名・事件名・制度名・概念など重要語句を 1 つだけ空欄にする
- 年号・西暦など「数字の年」を答えさせる問題は作らない
- 20〜30 枚生成する
- 分析テキストに記載された内容のみから出題する

### テスト問題

- **形式：4 択・年代整序のみ**（論述・語句記述は作らない）
- **難易度：標準 20% / 難しい 80%**（易しい問題は作らない）
- 構成比率：
  - ①一次史料問題（6 問）: 枠囲み資料の本文を引用して出題
  - ②教科書「問い」問題（8 問）: 教科書の問いを 4 択化
  - ③年代整序問題（2 問）
  - ④概念・因果問題（4 問）: うち 1 問以上は Web 上の資料を使用
- 問題文は試験問題として完結した自然な日本語にする
- 「教科書分析テキスト」「分析テキストによれば」などの表現は絶対に使わない

### 文字資料

- **目的**: 教科書が省いている「なぜ」「どのように」を補い、生徒が歴史の流れを自力で読めるようにする
- **扱う内容**: 因果関係・背景・結果のみ（年号の列挙・人物紹介は不要）
- **形式**: 短文を「→」でつないだ矢印チェーン
- すべての出来事を網羅しない。特に重要な経緯のみ **2〜4 テーマ** を選ぶ
- 1 テーマにつき矢印チェーンは **3〜6 ステップ**
- 各ステップは **15〜25 字程度**の短文
- Word 出力: テーマ名（游ゴシック・太字）＋ 矢印チェーン（游明朝）、矢印「→」は赤字

## プロンプト改善の手順

### analysis.txt の内容が薄い場合

`generate.py` の `ANALYSIS_PROMPT` を編集する。特に以下を充実させる：

- 「### 7. 一次史料・文字資料」: 枠囲み資料の本文転記が不十分なら精度向上の指示を追加

### テスト問題の質を上げたい場合

`generate.py` の `TEST_PROMPT_TEMPLATE` を編集する。

### 文字資料のテーマ選定・ステップ数を変えたい場合

`generate.py` の `MATERIAL_PROMPT_TEMPLATE` を編集する。特に以下を調整する：

- テーマ数（現在 2〜4）: 多すぎると散漫になるため増やす場合は慎重に
- ステップ数（現在 3〜6）: 長い経緯を追う場合は上限を引き上げる
- 字数制限（現在 15〜25 字）: 短くするほど読みやすいが情報が落ちる
