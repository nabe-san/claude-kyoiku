# 歴史シミュレーションv2 — CLAUDE.md

高校生向け歴史人物視点シミュレーションゲーム（ビジュアルノベル形式）のv2。  
v1（歴史シミュレーション）からUI・画像管理を全面刷新。HTML単体ファイルで動作。

---

## v1 との主な違い

| 項目 | v1 | v2 |
|---|---|---|
| 人物写真 | `images/`フォルダ参照（相対パス） | **Base64埋め込み**（HTML内に直接エンコード） |
| ステージ背景 | 真っ黒なグラデーション | **暖色系グラデーション**（写真が見えやすい） |
| キャラクター位置 | 中央 | **中央**（変わらず） |
| ゲームHUD | なし（v1も元々シンプル） | **なし**（ハート・好感度・メニューバー不要） |
| ステージ高さ | 420px | **460px** |

## シナリオ作成手順

### Step 1：人物・テーマ選定
- 教科書画像をアップロード → Claudeが登場人物・概念候補を提案
- 各候補に対して「このシナリオが深めさせる中核的な概念」を1〜2個提示する
- **先生の確認を取ってから Step 2 へ**（概念とシナリオの両方を確認）
- 対象概念は後述「中核的な概念一覧」セクションから選ぶ

### Step 2：資料収集
以下の優先順位で参照：
1. **最優先：ローカル読書データ**（`../books/`）→ 詳細は後述「参照できる読書データ」セクション
2. **概念確定の参照：中核概念参考資料**（`../参考資料/`）→ 詳細は後述「中核的な概念一覧」セクション
3. **補助：ウェブ検索**（上記に該当資料がない場合のみ）

### Step 3：テンプレートをコピーして編集

```powershell
Copy-Item -Recurse "scenarios/_template" "scenarios/XX_タイトル_人物名"
```

`scenarios/XX_タイトル_人物名/index.html` を開き、★マークのついたセクションを編集する：
- `CHARS`（キャラクター定義・写真）
- `SCENARIO_TITLE`, `PLAYER_ROLE_DESC`, `TL`（タイムライン）
- `P`（ストーリーデータ）
- `ENDING_NARRATION`, `SCORE_EVALS`, `CONCEPT_CARDS`

### Step 4：写真をBase64でHTMLに埋め込む

```powershell
# ① 写真をダウンロード（Wikimedia Commons などから）
Invoke-WebRequest -Uri "https://upload.wikimedia.org/..." -OutFile "temp.jpg"

# ② Base64エンコード
$b64 = [Convert]::ToBase64String([IO.File]::ReadAllBytes("temp.jpg"))

# ③ HTMLのCHARS定義に貼り付け
# photo: 'data:image/jpeg;base64,' + $b64  の形式で設定
```

HTMLの `CHARS` に設定：
```javascript
protagonist: {
  name: '桂太郎',
  photo: 'data:image/jpeg;base64,/9j/4AAQSkZJRgAB...',  // ← ここに貼る
  bg: 'linear-gradient(180deg, #6a7a5a 0%, #3a4a2a 100%)'
}
```

写真がない場合は `photo: null` → シルエットSVGが自動表示される。

### Step 5：index.html（トップ画面）を更新

`歴史シミュレーションv2/index.html` の `scenarios-grid` に新しいカードを追加する。

## 中核的な概念一覧（次期学習指導要領 2030年度実施予定）

> **出典：`../参考資料/` フォルダの資料に基づく。**  
> より詳細な定義・現代社会への接続例が必要なら `Read` ツールで参考資料のPDFを直接参照すること。

シナリオ作成前に、以下から対象概念を1〜2個選び、先生の確認を得ること。

### A. 第2次概念（思考の枠組み）

| # | 概念名 | 核心の問い |
|---|---|---|
| ① | 変化と継続 | 何が変わり、何が変わらなかったのか？ |
| ② | 因果と帰結 | なぜそうなったのか？意図せざる結果は何か？ |
| ③ | 歴史的重要性 | 誰が、なぜ「重要」と判断したのか？ |
| ④ | 歴史的パースペクティブ | 当時の人々はどんな世界認識のもとで判断したのか？ |
| ⑤ | 解釈と論争性 | 同じ出来事を異なる立場はどう解釈するか？ |
| ⑥ | 比較と相互の関連 | 異なる地域・時代の出来事は何が共通し、何が違うか？ |

### B. 実質概念（内容知的概念）

| # | 概念名 | 核心の問い |
|---|---|---|
| ⑦ | 近代化 | 近代化は人々に自由を広げたか、新しい支配を生んだか？ |
| ⑧ | 国民国家とナショナリズム | 国民国家は誰を「国民」とし、誰を排除したか？ |
| ⑨ | 帝国主義と植民地主義 | 帝国であった経験は今の世界にどんな遺産を残したか？ |
| ⑩ | 市民権・人権の拡張 | 「人権」は普遍的なものか、それとも特定の時代の所産か？ |
| ⑪ | 大衆化と総力戦 | 大衆参加の拡大は民主化と戦争動員をなぜ同時に進めたのか？ |
| ⑫ | グローバル化と相互依存 | グローバル化は誰を豊かにし、誰を取り残してきたか？ |
| ⑬ | 自由と統治（権力と権利） | 「自由」を制限することは、いつ・誰によって正当化されてきたか？ |
| ⑭ | 平等と格差 | 「機会の平等」と「結果の平等」のどちらが歴史的により拡大したか？ |
| ⑮ | 開発と環境 | 経済発展は長期的に人間社会の存立基盤にどんな影響を与えるか？ |

### C. 三層構造フレームワーク

上記A・Bの概念を三層に配置するとシナリオの「説明の軸」が定まりやすい。

| 層 | 役割 | 概念（例） |
|---|---|---|
| **構造層**（超上位概念） | どの時代・地域にも現れる、事件の背後構造を説明する軸 | 権力・国家・市場・共同体・正統性と権利・技術と情報・移動と交流・暴力 |
| **変化層**（歴史総合固有概念） | 近現代の大転換を名指す概念。単元の焦点化に使う | 近代化・産業化・国民国家・帝国主義・大衆化・総力戦・冷戦・脱植民地化・グローバル化 |
| **探究層**（操作概念） | 歴史をどう説明し・論証するかを支える枠組み | 因果と帰結・変化と継続・比較・観点と立場・史料と証拠・歴史的意義 |

**シナリオ設計の実践例（桂太郎シナリオ）：**
- 構造層：**国家 × 市場 × 暴力**（日露戦争の背後構造）
- 変化層：**帝国主義**（近代国家の対外膨張）
- 探究層：**② 因果と帰結・④ 歴史的パースペクティブ**（選択した概念）

**シナリオ設計の実践例（ローズシナリオ）：**
- 構造層：**市場 × 権力 × 暴力**（帝国主義の背後構造）
- 変化層：**帝国主義・植民地化**
- 探究層：**⑨ 帝国主義と植民地主義・④ 歴史的パースペクティブ**（選択した概念）

| `.char-photo` filter | sepia + contrast | **drop-shadow のみ**（自然な色で表示） |

### ナレーション行のステージ表示ルール（重要）
`speaker: null`（ナレーション）の行では、セリフボックスに名前ラベルは表示しないが、ステージには **`protagonist` の写真を表示する**。

```javascript
// テンプレートエンジンに実装済み（変更不要）
const displayKey = (!isStatus && !speakerKey) ? 'protagonist' : speakerKey;
```

- `speakerKey`（null）→ 名前ラベルなし
- `displayKey`（'protagonist'）→ ステージに主人公の写真を表示

このルールにより、ナレーションでシルエットが表示される問題が起きない。新シナリオで `speaker: null` を多用しても写真が消えない設計になっている。

## シナリオ設計の原則

### 教育目標
- 生徒が「当時の人物・立場の制約」を体感する
- 「なぜそう判断したか」の合理性を理解させる（**正解当てゲームにしない**）
- **各シナリオは必ず1〜2個の「中核的な概念」の理解を深めることを主目的とする**
- エンディングの概念カード4枚は、対象概念に直接つながる内容にする

### 決断場面の設計ルール
- 選択肢は2〜3個（多すぎない）
- 各選択肢に「当時の視点からは合理的に見える理由」を設ける
- 「正解」は史実の選択だが、それを押し付けない説明文にする
- 制約（財政・軍事・国際関係・国内政治）を必ず絡める

### 人物・立場の選び方の目安
- 高校「歴史総合」「日本史探究」の教科書に登場する人物・集団
- 明確な「決断の場面」が複数ある人物（単純な英雄譚にしない）
- 複数の視点・立場が存在する歴史的場面の中心人物
- プレイヤーの立場は特定の人物に限らず、**民衆・労働者・国民・植民地の人々などの抽象的な立場でもよい**
